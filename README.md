# PaperReader

Windows 中文论文阅读软件：导入 PDF 或 arXiv 论文，使用自己的 API Key 翻译与问答。

## 使用安装包

打开本地 `release/PaperReader-1.6.6-Setup-x64.exe` 安装，随后从开始菜单运行 **PaperReader**。发布到 GitHub 后也可从 [GitHub Releases](https://github.com/InfiniteHorizon0524/Paper-Translator/releases) 获取安装包。安装到当前用户目录，不需要管理员权限。软件已包含 Python 和依赖，**不需要 Python、pip 或虚拟环境**。已安装旧版时，可直接运行新版安装包覆盖升级，原有论文与译文保留。

免安装版：解压本地 `release/PaperReader-1.6.6-Windows-x64-portable.zip`，运行其中 `PaperReader/PaperReader.exe`。必须保留旁边的 `_internal` 文件夹。

支持 Windows 10 / 11 x64。桌面窗口使用 Microsoft Edge WebView2 Runtime（多数 Windows 系统已有）；如果不可用，会自动在默认浏览器中打开，也可从开始菜单选择 **PaperReader (Browser)**。浏览器模式的提示框用于退出后台服务，阅读结束后点击“确定”即可。

## 阅读论文

1. 点击“导入论文”，选择本地 PDF，或输入 arXiv 编号 / `arxiv.org/abs/` / `arxiv.org/pdf/` 链接，例如 `1706.03762`。旧版编号如 `hep-th/9901001` 也支持。
2. 点击“API 设置”，选择预设或填写兼容 OpenAI **Chat Completions 流式 API** 的服务地址、模型名称和 API Key。Base URL 填 API 根地址（例如 `https://api.example.com/v1`），不要包含 `/chat/completions`。模型名称使用服务实际提供的模型 ID。“测试连接”会发送一次简短 API 请求。
3. 默认进入原文与译文的宽幅“对照”视图，阅读区域占桌面窗口约五分之四。正文连续显示所有页面，未翻译页显示英文原文；可拖动中间分隔条调整栏宽，使用顶部目录与 Aa 调整阅读。左侧导航可收起，文献库支持来源筛选、搜索、排序和阅读进度。也可切换“原文 / 译文”，选择“翻译本页”或“翻译全文”。译文仅与论文绑定，修改 API Key、服务地址或模型后仍直接显示已有译文，打开论文无需先配置 API。全文翻译会跳过该论文已完成的页；翻译本页可重译并覆盖该页。切换其他论文或返回文献库时，翻译在当前窗口的后台继续，可同时翻译多篇论文；回到论文可查看实时进度，左侧显示正在翻译的进度。更改 API 设置只影响新任务，已有任务继续使用启动时的配置。停止或失败后，已完成页仍保存，重新开始可以继续；关闭或刷新窗口会停止未完成任务。左侧“我的论文”固定按导入时间从新到旧排序，点击阅读或修改文献库排序不会改变左侧顺序。原文可放大到 300%，点击百分比恢复适应宽度。
4. 点击顶部导航栏“论文助手”展开问答浮层，用中文提问，也可继续追问。默认不显示助手；点击顶部按钮、浮层的关闭按钮或按 Escape 可收起，保留当前对话与输入，生成中的回答也会继续。助手会将中文问题转换为英文检索词，再检索相关论文段落生成中文回答。点击回答中的页码会收起助手并回到原文；“检索参考”展开本次使用的段落。
5. “导出译文”保存为 Markdown，包括已完成的页；“下载原文”保存 PDF。所有导出在桌面窗口中会打开保存对话框。

译文正文中的中文使用宋体，非公式英文使用 Times New Roman。章节标题按 Markdown 标题层级加粗放大；脚注使用 `[^标记]` 与 `[^标记]: 注释`，统一在对应原文页的末尾用横线分隔，字号为正文的 75%。字号仍可在 Aa 中调整。图像保留在原 PDF，译文中只翻译图外的英文图片说明；原图位置显示虚线圆角矩形，点击或聚焦后按 Enter 会展开原始 PDF、跳转到对应页并标出图片区域，支持原文缩放。旧论文会自动更新定位信息，不必重新导入；页首图片的旧译文会依据图题自动去除图内文字与子图标签，用一个圆角矩形代替整图，保留图外说明和后续正文，无需额外 API 调用；旧译文若缺少标题、脚注或图片位置标记，可用“翻译本页”重新生成。复杂排版的图形区域与脚注识别可能需要结合原文核对。

译文和论文助手支持 Markdown 表格，包含表头、左 / 中 / 右对齐、粗体、代码、行内公式与页码引用。宽表格在阅读栏内横向滚动，可点击表格后用方向键滚动。普通文字中的竖线使用 `\|`，单元格换行可用 `<br>`。已有 Markdown 表格会直接渲染；旧译文若把表格写成普通文字，可用“翻译本页”重新生成。导出的 Markdown 保留表格结构。表格根据 PDF 文字提取与模型输出生成，原 PDF 中复杂合并单元格或提取残缺的表格仍需结合原文核对。

译文和论文助手支持 LaTeX 公式：`$...$` / `\(...\)` 显示行内公式，`$$...$$` / `\[...\]` 显示独立公式，支持分数、上下标、矩阵、多行对齐与 `\tag{编号}`。公式渲染器和字体随软件内置，无需联网加载；长公式可横向滚动，无法解析的公式保留 LaTeX 原文。代码块中的公式保持代码形式。已有译文中的 LaTeX 会直接渲染；若旧译文没有公式标记，可用“翻译本页”重新生成。导出的 Markdown 保留 LaTeX 源码，需在支持数学公式的 Markdown 阅读器中查看。

左侧“我的论文”在每篇论文下显示“已翻译 3/10 页”等进度，仅统计已完成并保存的页面，重译不会重复计数，重启后仍会显示。“翻译本页及之后页面”从当前阅读页开始，一直翻译到最后一页，跳过已完成页面；支持停止后再次点击继续，也可切换论文让任务在后台完成。

每篇论文默认处于“翻译锁：已解锁”状态。满意当前译文后，点击底部的翻译锁即可锁定这篇论文：翻译本页、翻译本页及之后页面、翻译全文与重译全文按钮会禁用，锁状态在重启后保留。翻译过程中锁定会停止该论文的任务，并显示已完成的译文；再次点击解锁后可继续翻译或重译。锁定后仍可阅读和导出已有译文。完成、停止和错误消息在右上角显示，长消息自动换行。

API 设置中的“思考强度”由翻译与论文助手共用，包括助手的英文检索关键词生成。可选服务默认、关闭（none）、极低（minimal）、低（low）、中（medium）、高（high）、极高（xhigh）和最高（max）。选择后自动保存在本机，无需点击“保存设置”，直接关闭设置窗口或重启软件后仍恢复最后选择的档位；尚未配置 API 时也可保存，旧版配置自动使用服务默认。单独修改强度不会保存其他未提交的 API 字段，保存失败会提示并恢复此前档位。已有翻译与问答任务保留启动时的强度，保存后的设置用于新任务。服务默认由模型服务决定，其他档位通过 Chat Completions 的 `reasoning_effort` 参数发送；支持的档位依赖模型与服务，较高强度通常增加耗时及 Token 用量，详见 [官方 OpenAI 文档](https://developers.openai.com/api/docs/guides/reasoning)。

## 跨页翻译

1.6.2 在翻译每个片段时提供前后正文、跨页句子的语义参考以及前文译文。图片、图题、表格、表题、脚注和页码不会被当作正文续句；长页优先按段落与完整句子拆分，表格和独立公式保持完整。单独翻译某一页也能参考相邻正文，页码、图片位置和原文对应关系保持不变。上下文提取是排版启发式，复杂布局和模型生成结果仍需结合原文核对。

旧译文不会自动改写或自动调用 API。更新后可点击“重译全文”，按新规则逐页替换已有译文；仍可使用“翻译本页”只重译问题页。跨页句子建议将前后两页都重译。“翻译全文”继续跳过已完成页，保留断点续译行为。重译使用已配置的 API，按服务商规则计费。

## 数据与 API

- 旧版按服务和模型保存的译文会自动合并；每页使用最近保存的版本，旧版本保留在本地数据库备份表中，删除论文时一并删除。
- 论文 PDF、按页文本和译文保存在 `%LOCALAPPDATA%\PaperReader`；重启后仍可阅读。删除论文会删除相应 PDF 和译文。
- API 地址、模型和 API Key 保存在 `%LOCALAPPDATA%\PaperReader\api-settings.json`，启动时自动恢复，不必每次重新配置。Key 使用当前 Windows 账户的 DPAPI 加密，文件中不保存明文 Key；浏览器本地存储仍不保存 Key。API 设置界面显示实际保存路径。若设置了 `PAPERREADER_DATA_DIR`，配置文件保存在该目录下。
- 翻译与问答时，相关论文文字会发送至用户指定的服务。软件不提供内置 API Key；API 用量由服务商按用户账户计费。全文翻译通常比单页翻译使用更多额度。
- API 支持自定义 HTTPS 地址。本地模型可用 `http://localhost:11434/v1`（Ollama 的 OpenAI 兼容端点），模型名称需与本机已下载模型一致，Key 填任意非空值，例如 `local`。
- arXiv 下载需要网络；无法访问时可在浏览器下载论文后上传。

## 当前范围

支持带文字层的 PDF，最大 50 MB、500 页。扫描 PDF 需要先进行 OCR。原文以按页图像展示，完整保留排版与公式；译文根据提取出的文字生成，不重建原 PDF 排版，复杂表格、特殊公式和多栏文字可能需要人工核对。长篇问答使用关键词检索的相关片段，并非每次将全文发送给模型；答案应结合引用原文验证。对话只保留在当前窗口，译文会持久保存。

## 从源码运行与构建（仅开发者需要）

构建机器需要 Windows x64、Python 3.12+，**使用者不需要这些环境**。可直接将依赖装到项目目录，不使用虚拟环境：

```powershell
python -m pip install --target .deps -r requirements-dev.txt
python launcher.py
```

本地开发浏览器模式：`python launcher.py --server --port 8765`，然后访问 `http://127.0.0.1:8765`。可设置 `PAPERREADER_DATA_DIR` 指定数据目录。

测试（浏览器回归与 UI 验证需要本机已安装 Google Chrome）：

```powershell
$env:PYTHONPATH = "$PWD\.deps"
python -m pytest tests -q
python scripts/ui_smoke.py
python scripts/translation_smoke.py
```

构建：安装 Inno Setup 到 `.tools/inno`，准备 `installer/ChineseSimplified.isl` 后运行：

```powershell
python -S scripts/build.py
```

如果旧版正在运行，可使用 `python -S scripts/build.py --dist-dir dist/v1.6.6` 在独立目录构建，新版安装包与免安装 ZIP 仍输出到 `release`。

构建脚本生成独立目录、免安装 ZIP 和安装 EXE；测试打包运行：`PaperReader.exe --smoke-test`。依赖许可见 `THIRD_PARTY_NOTICES.md`。当前安装包未进行商业代码签名。

实现参考：[OpenAI Chat Completions 官方接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[arXiv 官方 API 手册](https://info.arxiv.org/help/api/user-manual.html)、[PyMuPDF 文字提取文档](https://pymupdf.readthedocs.io/en/latest/recipes-text.html)。
